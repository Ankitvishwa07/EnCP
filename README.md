# Household Energy Forecasting with an Agentic Energy Advisor

## Setup on your local machine

### 1. Requirements
- Python 3.10 or newer
- Git

### 2. Clone the repository
```
git clone https://github.com/YOUR_USERNAME/energy-advisor.git
cd energy-advisor
```

### 3. Create a virtual environment and install libraries

Windows (PowerShell):
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

macOS / Linux:
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 4. Download the dataset
1. Download "Individual household electric power consumption" from the UCI Machine Learning Repository.
2. Unzip it.
3. Create the folders `data/raw`, `data/processed`, `models` and `results` if they don't exist:

Windows: `mkdir data\raw, data\processed, models, results`
macOS / Linux: `mkdir -p data/raw data/processed models results`

4. Put `household_power_consumption.txt` inside `data/raw/`.

### 5. Run the pipeline (in this order)

Windows (PowerShell):
```
$env:PYTHONPATH = "src"
```
macOS / Linux:
```
export PYTHONPATH=src
```

Then, from the project root:
```
python src/data_prep.py
python src/eda.py
python src/features.py
python src/baselines_trees.py
python src/lstm.py
python src/transformer.py
python src/compare.py
python src/agent.py
python src/prep_dashboard.py
```

Training the LSTM and Transformer on CPU can take from several minutes up to an hour.

### 6. Start the dashboard
```
python -m streamlit run app/dashboard.py
```
Open http://localhost:8501 in your browser.

## Troubleshooting
- **`ModuleNotFoundError: config`**: set `PYTHONPATH` to `src` again (it resets in every new terminal).
- **`FileNotFoundError: data/processed/...`**: run the scripts in the order above, from the project root.
- **Large files are not in the repo**: `data/` and `models/` are generated by the scripts.
